# Local-only inputs

Never commit proprietary original game data to this public repository. Keep `.BUN`, `.ELF`, `.chunk`, textures, converted models and generated game data in ignored local fixture directories.

For the Wii RedBuilding fixture, research documents record an 8,488-byte scene ROOT with SHA-256:
`cb08ca728a9b76992aaaefe32b450565ef53246f090cfe296f77d96c5d272e7f`.

The original Carbon world BUN and complete V42 donor/candidate root pair are required for genuine PC root cross-validation. Until verified source bytes are available, original Carbon PC scene-layout assertions must remain unconfirmed.
