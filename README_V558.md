# V554–V558: native DSP control and original audio reset groundwork

## Verified results (2026-11-24)

- V552 standalone timed ARAM DMA: [run 45427928478](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45427928478) passed 16 profiles. Bidirectional 32-byte transfers, inert polling, bounds, W1C and shared PI preservation.
- V553 generated native PPC: [run 45428251593](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45428251593) passed 16 trials each in split and nonsplit mode. Actual native MMU and MEM1/MEM2 data copying, no interpreter.
- V554 shared DSP control: [run 45428907732](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45428907732) passed 32 trials, including independent DSP/AI/ARAM interrupt masks and status, explicit reset/init completion tokens and two directional mailboxes.
- V555 revised single-owner DSP control and ARAM regression: [run 45429088763](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45429088763) passed 16 ARAM and 32 DSP control trials. The actual generated-PPC combined DSP integration run [45429088787](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45429088787) is pending; no claim of its success yet.
- V556/V557 audio reset witness: [run 45429635030](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45429635030) passed geometry, patch composition and audit gate tests plus 18 negative controls using the real stateful ACR binding. All six RMW operations and five guest virtual timebase delays are checked, including 32-bit wrap. This is an original-free regression, not owner execution.

## New code and scope decisions

- DSP control composes peer interrupt status with the existing ARAM PI owner, avoiding separate writers that could clear one another's interrupt. The single-owner lease prevents duplicate DSP control attachments. The opt-in combined binding exposes bounded 16-bit mailbox/control and 32-bit DMA register access.
- Reset and init requests are explicit tokenized backend events. No DSP mailbox reply or transition completion is generated by a read or polling loop. A real DSP execution or separately verified service backend remains necessary.
- V556 authenticates the original audio entry/reset calls, ten timebase callsites and return boundary. Its witness records successful native ACR operations and checks virtual-time ordering without changing original instructions or memory. Time is NWiiRuntime's virtual instruction clock, not physical PLL settling time.
- V558 [private static startup geometry](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45429775741) authenticates SI, SRAM, thread and audio call chains without expensive AOT recompilation. Only bounded scope/verification results are printed. Pending at checkpoint. Does not prove execution.

## Original startup and blockers

The earlier Linux SI-return attempt [45422869760](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45422869760) used the superseded pre-V546 initialized-flag expectation and failed with rc=106 before SI discovery. No regression in the new DSP or ARAM code is implied. The corrected Linux [45426293326](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45426293326) and Windows [45426502167](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45426502167) synthetic build jobs passed. Linux private compilation is queued; Windows private complete-image compilation is running. V551 private NAND successor replay [45427637226](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/45427637226) remains in progress, with public tests passed.

Do not enable SRAM, thread or audio owner continuation before the preceding original boundary is verified. Do not activate the new DSP register model in the original boot lane until its reset/init/mailbox backend is validated. It currently models no DSP ISA or audio playback. No proprietary game binaries or translated code are included, and no full OSInit, main, frame or gameplay has been verified.
