# V572: direct-call-only installed SC overlay and full-image translation preflight

The V561 overlay adds a native vector entry to generic generated dispatch tables. A generic PC transfer must not bypass the authenticated one-shot SC route. V572 validates the seven original vector labels/bytes and generated RFI implementation, removes the vector function from the generic bounds and switch tables, and rejects any normalized address inside the 28-byte overlay before ordinary dispatch. The direct native function remains available to the verified route. The focused generated fixture checks all 28 byte addresses plus cached/physical aliases, six route refusals and successful normal direct execution. The private owner workflow additionally attempts the complete original DOL + ELF-sized map with the full cache/runtime patch chain and the overlay opt-in; it verifies generated vector provenance and direct-only dispatch without linking or launching that complete image. CI pending. No production startup scope enables the overlay yet.
