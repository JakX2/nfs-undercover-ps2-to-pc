# V684: authenticate shared GPR-save entry without exclusive ownership

V682 original geometry proved the first direct dependency is interior to one sized ELF function with no separately sized root (exact_root=0, containing=1). V684 adds a tightly restricted fallback: only a DOL/ELF-identical consecutive GPR-save suffix recognized by V683, contained within that unique original function, can be authorized. Unlike independent SI roots, this shared alias is not included in exclusive analyzer ownership, preserving all sibling entries. Only automatic HLE selection for the exact alias root is cleared. Its unique emitted root, native direct call and complete suffix are separately audited without rejecting legitimate labels in other roots. At runtime the helper must return with preserved ABI and every expected register word actually saved in mapped MEM1. Unsupported shapes (including FPR suffixes) remain refused. Original classification and translation/execute verification pending; no original data is published. Added synthetic alias ownership and three actual save-witness cases.
