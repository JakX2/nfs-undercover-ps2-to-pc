# V814: targeted original timebase retry regression

V811 owner tests verified all 16 original system-time returns with 14 nonzero offsets, two modulo-64-bit wraps and six refusals, but its near-rollover trials did not produce an actual retry. V814 measures the first upper-word timebase read's native tick delta in the existing original fixture, then seeds the next independent trial so the first TBU sample is precisely 0xffffffff. The original low/high sampling sequence must cross the 32-bit boundary and retry. The reusable witness must accept the exact pending poll(s), repeated timebase reads, final sample and original system-time return. No scheduler or guest instruction is replaced. One targeted original retry per split/nonsplit mode is required; tests pending. This is still an isolated owner fixture, not a continuous boot result.
