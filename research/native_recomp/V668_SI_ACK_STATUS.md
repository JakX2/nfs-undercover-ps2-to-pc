# V668: first SI completion acknowledgement observer

V667 is separately queued for complete-image native SI handler selection. V668 builds a reusable opt-in observer of the real SI controller's first transfer-complete W1C, actual PI source deassertion, preservation of unrelated PI causes and mask, and exact next instruction boundary. It includes original-free trials against the actual SiController and SiTypeScheduler with an explicitly absent port; it does not invoke any original game handler. The private owner geometry job authenticates the original SI handler extent, 32-bit store candidates, and call roots without publishing words or generated game code. The optional SI binding seam is unit-tested but not installed in the complete-image runner: the original handler entry and store label geometry must be verified before activating it. It deliberately rejects combined ACK/new-transfer writes, mask-only clearing, unsupported stores and helpers without a matching native instruction witness. No claim of real original ACK, RFI, queue progression or boot.
