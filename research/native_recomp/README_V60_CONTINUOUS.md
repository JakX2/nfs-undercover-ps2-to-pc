# V60: original SRAM initialization with EXI DMA (candidate)
Restores the original SRAM read, cache invalidation, immediate command, DMA read/synchronization, EXI unlock, and read-only configuration comparison. The device model responds through the original MMIO transaction and copies exactly 64 synthetic SRAM bytes only when the DMA becomes idle. No guest SRAM injection at function entry. The original configuration is chosen to require no subsequent write; SRAM writes, error paths and queued EXI callbacks remain unverified. The source-only dcbi patch adds separate data-cache trace and host fence, not cache hardware emulation. Verification pending.
