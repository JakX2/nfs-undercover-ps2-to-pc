# V720: focused original OS context loader and native RFI

A new independent private fixture extracts only the authenticated 54-instruction original context loader and translates it alongside a separately authored resume/stop program. It checks native label ownership, no fallback or HLE, and the exact original terminal RFI and branch geometry. The test seeds a synthetic exception-state OSContext with varied integer state, SRRs and GQRs, deliberately damages live CPU state, and uses the V706 witness to verify native loader restoration and both RFI polling boundaries before actually executing the independent resume instruction. The negative trial alters one saved GPR, which must be refused at the original RFI boundary. The OSContext layout and expected exception flag clear are fixture hypotheses to be validated by owner execution. No original interrupt delivery, scheduler, FPU restoration, original resumed startup, or complete boot is claimed. The private run is separate from V719 complete-image CI. All source bytes and generated code are scratch-only; the public log reports only bounded counts and mismatch classes.
