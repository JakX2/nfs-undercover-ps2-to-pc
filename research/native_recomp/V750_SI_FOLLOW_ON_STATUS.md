# V750: observe a real follow-on SI type transaction after W1C

The existing first-ACK witness deliberately requires SI quiescence and refuses a second COMCSR start. V744 identifies possible later __SITransfer/SITransfer paths but no such dynamic operation is proven yet. V750 adds an independent observer for a single exact type-discovery request following a real first completion/acknowledgement. It checks request token, full communication RAM snapshot, channel and command geometry, unchanged unrelated PI sources/mask, pending state, minimum completion time, and the explicit endpoint response or absence. It never performs the MMIO write or advances the scheduler. Exposes only a read-only backend issued-token count; original first-ACK behavior remains unchanged. This is a preparatory synthetic device-level control, not permission to accept original follow-on transfers. CI pending.
