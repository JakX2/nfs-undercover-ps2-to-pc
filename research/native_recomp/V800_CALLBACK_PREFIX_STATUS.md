# V800: reusable live callback prefix witness

V798 owner-context 139023888895 passed eight original prologue/save executions and a corrupted-stack refusal in each generated mode. V796 owner-preflight 139020520611 passed complete-image callback identity composition. V800 extracts an independently written read-only runtime witness for a candidate indirect branch, exact native callback and save entries, complete register and bounded stack snapshots, exact original instruction words, and contiguous native ticks through the first unexecuted post-save instruction. It never dispatches the candidate, modifies guest memory, or permits arbitrary original callback execution. The caller must separately authenticate complete candidate identity and device state. Synthetic controls cover mapping, target identity, context corruption, tick gaps, saved-word tampering and device loss. The witness is not yet installed in the continuous route; dynamic callback identity and original alarm execution remain prerequisites. CI pending.

V801: aligned the live observer with the pinned emitter's linear-label semantics. The generated label argument, not a potentially stale ctx.pc, authenticates each ordinary instruction; ctx.pc is still checked at native entries and the actual save return. A synthetic successful control deliberately retains the entry PC through linear labels. This is a witness-only change, not a guest PC mutation.

## V804: actual indirect dispatch handshake

V801 original-free job 139024935744 passed two valid and fourteen refused observer controls. The pinned upstream bctrl implementation writes LR and PC, then returns to the outer dispatcher instead of directly invoking the target. The outer loop polls pending callbacks and increments inst_count once before native entry. V804 adds an explicit separate dispatch lane, checks the exact poll with unchanged state, accounts for precisely one dispatch tick at the native entry, and refuses unaligned raw CTR because the pinned emitter does not mask it. Direct-call fixture semantics remain unchanged. Adds one successful outer-dispatch case and seven refusals for malformed CTR, LR, timing, missing/duplicate poll and lost device state. No live dispatch is authorized; full-image integration must separately account for the SI device witness on the dispatch tick.
