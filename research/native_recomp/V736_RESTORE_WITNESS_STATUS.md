# V736: exact read-only GPR restore witness

V735 tests the original 15-load alias in isolation. V736 adds a reusable runtime witness for any independently authenticated contiguous nonvolatile GPR restore leaf. It requires the exact linked call and expected guest words, validates all saved memory against the handler-entry register snapshot, checks every progressively restored GPR and unchanged unrelated registers, then verifies the exact native LR return and instruction counts. No guest state is written by the witness. Twenty independent tests cover 1/15/18-register variants, wrong memory or call, wrong entry, corrupted native state, missing tick and wrong return. This contract is not yet installed into the complete image; the original V726 observed dynamic boundary is required before broadening the route.
