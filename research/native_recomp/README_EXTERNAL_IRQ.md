# Native external IRQ entry

Original-free bounded entry at cached low-memory vector `0x80000500` from an explicitly resumable guest instruction boundary. The helper checks PI/MSR interrupt eligibility, refuses nested dispatch or unsupported vector/endian modes, authenticates the installed vector, saves the current guest PC in SRR0 and masked MSR in SRR1, then enters exception mode. It does not acknowledge hardware, execute the handler, switch threads or emulate `rfi`. The IOS bus now waits for the previous Hollywood IPC IRQ latch to be cleared before accepting the next service tick. The test exercises real native IOS ACK/reply transport, deferred/masked delivery, corrupted vector rejection, preserved register state and notification ordering with synthetic CPU state. References: IBM 750CL manual chapter 4 https://fail0verflow.com/media/files/ppc_750cl.pdf ; WiiBrew hardware IPC https://wiibrew.org/wiki/Hardware/IPC ; public Dolphin IPC readiness behavior https://github.com/dolphin-emu/dolphin/blob/master/Source/Core/Core/HW/WII_IPC.cpp .
