# V683: strict independent register-save leaf classifier

The first original SI direct dependency lacks a successful conventional extent preflight; precise V682 classification is still pending. V683 adds an independent PPC-semantic recognition control for compiler register-save suffix aliases, including consecutive nonvolatile GPR/FPR stores into fixed frame bases and exact return. It verifies every inspected original word in both private DOL and ELF, counts raw executable ELF symbol types including zero-sized entries, and emits only classification counts. No authorization, analyzer change, runtime substitution or original execution is added. 72 synthetic register-save suffix patterns plus negative and identity cases are tested in CI. If actual geometry differs this classifier will refuse it.
