# V697: authenticate real SI word reads and diagnose unsupported accesses

The ACK-only runtime previously witnessed actual stores but did not distinguish completed guest reads from host probes. V697 associates each active SI MMIO word read with its authenticated PPC load label, contiguous tick, device identity and held source, and consumes the visit so a duplicate/stale read cannot be accepted. Prior inactive sampling/discovery and normal MMIO behavior remain unchanged; armed unsupported widths/registers receive bounded redacted diagnostics before backend execution. Existing write and ACK checks remain. Original-free compiled binding adds valid read-to-ACK, stale/wrong-op reads and unsupported width/register cases; total 18 process cases. Original owner validation pending. This guard is deliberately bounded to currently supported SI word-load forms.
