# V1384 deferred STM cache syscall contract

The existing native Open SC route requires EE=1 and a cold first/second transaction snapshot. The asynchronous STM request has EE=0 and exactly four completed IOS service steps with both descriptors open. Add a separate explicit DeferredStm mode for the two original IOS_Ioctl buffer flush callers and the common request-header flush caller. Require exact native vector/RFI, stable broker snapshot, both descriptor identities and unchanged unrelated registers. Preserve existing default mode and its tests. The new suite exercises both actual broker descriptor orders and all three callsites with negative cases for stale epoch, wrong mask, wrong caller, mailbox changes and vector/return corruption. Original third request execution remains unverified.
