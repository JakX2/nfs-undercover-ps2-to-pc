# V755: distinct authenticated handler call slots

The original handler can invoke multiple different helpers after the V719 boundary. The previous V738/V742 shared witness intentionally allowed only a single helper invocation, so a future composed route would reject a valid later restore after time. V755 preserves the old single-call API while adding explicitly selected bounded slots (1..12); a slot can be completed only once, with exact call/return tick and PC checks, no overlapping calls or poll during an in-flight call. The current private bindings explicitly use slot 3 for time and slot 12 for restore (still separate opt-in scopes); each retains its own native callee verifier. No new callsite, callback, MMIO or original route is authorized. Legacy and new synthetic tests pending CI.
