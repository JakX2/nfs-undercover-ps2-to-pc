# Native IOS MMIO bus

Unifies the native IPC mailbox, STM broker, Hollywood IRQ controller, PI cause/mask, and the MSR.EE eligibility gate. Guest writes use actual physical register addresses or Hollywood mirror, scheduler ticks drive separate ACK and reply transitions, and the pending external interrupt is derived rather than fabricated. A caller-provided physical RAM adapter owns memory safety. The STM dispatcher now validates the entire 0x40-byte aligned request, protecting private trailing fields from output overlap. This is source-only, not CPU exception delivery or original guest integration yet. References: https://wiibrew.org/wiki/IOS, https://wiibrew.org/wiki/Hardware/IPC, https://wiibrew.org/wiki/Hollywood/IRQs, https://wiibrew.org/wiki/Hardware/Processor_Interface. CI pending.
