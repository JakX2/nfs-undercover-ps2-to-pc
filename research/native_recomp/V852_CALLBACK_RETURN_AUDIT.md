# V852: explicit live wrapper and callback-return launch modes

Adds the opt-in --run-si-wireless-wrapper and --run-si-callback-return modes, preserving every earlier default. The wrapper-only route uses V848. The callback-return route uses the new V852 audit: genuine earlier V847 result, matching original handler ordinal, bounded suffix visits, and exactly one ABI-verified original callback return across the native dispatcher. A changed setter or getter can still stop at the previously authenticated V847 boundary; a newly encountered indirect callback is classified and not executed. Those outcomes are explicitly reported with callback_return=0. No mode is automatically dispatched by this commit. V839 original execution and V850 private preflight remain the required gates for expensive new live runs.
