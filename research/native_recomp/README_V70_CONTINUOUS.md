# V70: original STM initialization to first IOS_Open entry (verified)

Authentic owner DOL/ELF metadata identifies __OSInitSTM at 0x8052B034, 0x118 bytes, and the IOS_Open call at 0x8052B08C. This continuation restores the original post-IPC OSInit branching and the complete STM function, but stops explicitly at IOS_Open entry 0x80519944. It validates prior IPC state on STM entry, seeds only original initialized SDA operands for the STM prefix from the authenticated owner file, and validates the original device pathname pointer and mode. Other IOS entry and alternate startup paths remain nonreturning test-only boundaries. No IOS syscall is serviced and OSInit has not returned. The separate V69 verified lane is retained. Owner-focused CI [44222713993](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/44222713993) passed sixteen original native startup trials including pathname/mode checks with exact checkpoint `0x80519944`, on `08972e5d6ab63919613b123035ef960a54c7d165`.

Follow-up integration candidate routes the original startup PI and Hollywood interrupt mask writes and IPC control write into the reusable IOS bus. The owner memory adapter only exposes physical contiguous MEM1/MEM2 to IOS. This does not execute an IOS request yet. The previous V70 proof is independent.

The integrated owner V70 run [44223912932](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/44223912932) passed all 16 trials with the original MMIO writes routed through `IosBus` on `64be40883fefb1c4c50814ffab0b1d6c5800cf53`.
