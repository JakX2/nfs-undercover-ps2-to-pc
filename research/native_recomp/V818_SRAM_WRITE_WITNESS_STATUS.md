# V818: reusable SRAM write completion witness

V815 native-device job 139034138613 passed all 64 offset-addressed SRAM transfers and eight refusals, including prior MX and EXI scheduler regressions. V818 adds a read-only observer for one exact write transaction, from deselected baseline through command, payload chunks and final deselection. It validates source device/controller identity, increasing real tokens, one chip-select epoch, command encoding, exact byte-level payload, dirty state and full completion without modifying guest or device memory. The original-free suite uses the actual EXI controller, MX endpoint and scheduler for 64 successful offsets and 16 deliberately invalid observations. It is not installed in continuous startup yet; actual guest write traffic must first reach this subsystem. CI pending.
