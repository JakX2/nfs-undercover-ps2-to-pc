# Native STM IOS service lane

Original-free service dispatcher, implemented independently against the documented Wii IPC/STM interface. Handles the two STM paths, bounded descriptor allocation, close, idle-state query, deferred event registration, explicit host event delivery and release. The transport reads a validated physical guest request header, acknowledges X1, defers replies until the ACK is cleared, then writes the big-endian reply and raises Y1. Unknown paths and unsupported commands fail; no host shutdown, filesystem access or generic success stub. Tests are source-only. Not wired to original IOS_Open or the guest IRQ dispatcher yet. Hardware timing, additional IOS devices, cache visibility and guest scheduling remain unimplemented. Public references are listed in the header. Source-only CI [44222607722](https://github.com/JakX2/nfs-undercover-ps2-to-pc/actions/runs/44222607722) passed all STM device and transport tests under ASan/UBSan on commit `9d6eaecce71ed1cc1efb725a31428c194caced0f`.
