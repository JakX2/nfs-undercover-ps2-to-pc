# V850: full-image original callback return preflight

Composes the owner-proven V841/V846 callback suffix and compiler return, V849's optional outer-dispatch witness, and the authenticated V847 wrapper. Captures the actual pre-bctrl CPU state and selects one of two original handler resume labels. The return observer checks both exact native resume dispatch cases, guards shared restore hooks, accounts for the existing dispatcher tick and stops before the first handler instruction executes.

Only the unchanged setter return enters this route. The changed setter still stops before EXILock executes, the getter retains its V847 boundary, and any original indirect callback reached after the setter is classified but not executed. No new live launch mode or CPU state injection is provided. Owner preflight pending; live callback return, handler continuation and boot are not yet established.
