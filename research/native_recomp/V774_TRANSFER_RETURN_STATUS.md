# V774: complete original SI transfer CPU observer

V770 verified the real original transfer on all channels and busy lanes; V772 verified the device seam. V774 extends the V768 prefix observer into a separate complete transfer witness. It retains the old ACK ownership through the original save and disable leaves, hands off after the disable BLR, and uses V772 for every subsequent native instruction and actual MMIO. Exactly one of the two authenticated interrupt restore callsites and the original six-GPR restore must return. Check original caller ABI, result, guest SI metadata and transaction state (pending or completed). The observer stops before executing the next handler instruction and does not yet support further handler or IRQ work. Scheduler configuration is read from the same live controller and exact advanced tick. No runtime installer enabled in this commit; focused test and private binding follow.
