# V570: explicit one-shot boot SC dispatch route

Adds a reusable scoped route for the authenticated cache-flush syscall and exact boot caller. The V438 instruction tick is checked across an injected pre-SC trace, installed and source bytes must match, no active dispatch or EE is permitted, and exactly one native vector-entry trace plus seven native vector instructions and the expected synchronization counts are required. The RFI/BLR path is verified without a general-purpose syscall replacement. Unrelated calls retain the existing dispatch path; an unarmed or mismatched targeted call fails closed. The independent generated fixture tests 32 trials, six refusals, one delegation and CPU-stop propagation, with the owner variant gated on synthetic success. No complete-image observer has been connected yet. CI pending.
